Open Tools

Free, open-source tools for researchers and students. No sign-up, no tracking. Click a tool to open it.

JournalFree

For researchers and PhD students

Find high-impact (Q1) journals you can publish in without paying an article processing charge.

  • Search and filter by subject, publisher, speed
  • Compare journals side by side
  • Unverified impact factors clearly flagged
▶ Open JournalFree Source
⚙️

OS-Sim Lab

For CS students and teachers

Watch operating-system algorithms run step by step, then practise and get your answers marked.

  • CPU scheduling with Gantt charts
  • Page replacement and Belady's anomaly
  • Banker's algorithm and resource requests
▶ Open the simulator Source
🫁

lungct-kit

For medical-imaging AI researchers

A Python library that loads LUNA16 and LUNA25 lung CT data in one line, with leakage-safe patient splits.

  • Correct world-to-voxel coordinates
  • Resampling, lung window, nodule patches
  • Plugs straight into PyTorch
📖 Open the docs Source
